Transmission Guide

1. Mount the phone on the vehicle dashboard for clear sky visibility to GPS satellites.

2. Keep this page active and screen on. Wake Lock is engaged automatically when tracking.

3. Ensure the phone has an internet connection (mobile data works fine).

4. Tap Start Live Tracking — your position will appear on the fleet dashboard within seconds.

5. If the server is temporarily unreachable, location updates are buffered and flushed automatically on reconnect.

GPS Access Blocked

Modern browsers require a secure connection (HTTPS or localhost) to access device location.

Option 1: Use Simulation Mode (For Testing) Enable the GPS Simulation Mode switch on the setup card or tap the Quick Test button. This works instantly on HTTP without physical GPS access.
Option 2: Bypass Browser Check (Android Chrome) On Chrome on the device, navigate to: chrome://flags/#unsafely-treat-insecure-origin-as-secure Enable the flag, add your tracker URL (), and relaunch Chrome.
